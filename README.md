# Vizuka TopUp V2
First storefront/admin prototype.

Included:
- Mobile responsive storefront
- Product categories
- Price editing
- Availability ON/OFF (no quantity stock)
- Player UID and payment method order form
- Order ID generation
- WhatsApp contact
- Basic SEO metadata

IMPORTANT: the current admin/order demo uses browser localStorage. It is NOT a real shared database and should not be used for live payment operations.

Next phase: secure backend/database, real admin/staff authentication, shared orders, payment verification/proof upload, and later a server-side top-up API. Never expose API keys in frontend code.
